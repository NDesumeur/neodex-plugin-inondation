# Inondation

La tache du coin prend la couleur que tu choisis et avale ses voisines de même couleur. Couvre toute la grille en un nombre de coups limité.

Chaque coup change la couleur de ta tache : elle s'agrandit de toutes les cases voisines de cette couleur. Couvre les 196 cases avant d'épuiser tes coups. Les niveaux donnent de moins en moins de coups.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Inondation → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
